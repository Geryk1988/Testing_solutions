# idq-gsnowintg - Kafka Consumer Microservice

Rebuilt from the original `EventsConsumerwithSASLSSL` core Java application
into a Spring Boot 2.7.18 microservice, using the exact pom.xml, versioning,
and project identity from the original source.

## File and Method Description

### `IdqGsnowintgApplication.java`
Entry point of the Spring Boot application.

| Method | Description |
|--------|------|
| `main(String[] args)` | Starts the Spring Boot context. Added `@EnableScheduling` annotation that activates the scheduler mechanism responsible for stopping the application after a configured time. |

---

### config / `ConsumerProperties.java`
Loads all startup parameters from an external `.properties` file via `ReadPropFileService` and exposes them as typed Java fields.

| Method | Description |
|--------|------|
| `init()` | Annotation `@PostConstruct` — fires automatically after `ReadPropFileService` is loaded. Maps keys from the properties file to class fields (brokers, groupId, topic, filters, file paths, duration). |
| `getDurationMs()` | Converts the value of `DURATION` and `DURATION_UNIT` to milliseconds. Supports units: `s` (seconds), `m` (minutes), `h` (hours). Defaults to minutes. |
| `require(String key)` | Private helper method - Gets the required key from the properties file. Throws an `IllegalStateException` if the key is null or missing. |
| `intOrDefault(String key, int def)` | Private helper method - Gets the value as an `int`, returning the default value if the key doesn't exist or can't be parsed. |
| `longOrDefault(String key, long def)` | Private helper method - As above, but for values ​​of type `long`. |

---

### config / `KafkaConsumerConfig.java`
Builds a Spring Kafka bean based on parameters from `ConsumerProperties`. Configures a SASL/SSL connection to the broker.

| Method | Description |
|--------|------|
| `consumerConfigs()` | Creates a Kafka consumer configuration map. Sets brokers, group IDs, deserializers, SASL/SSL (PlainLoginModule, truststore), Schema Registry (optional), poll parameters (timeout, max records, heartbeat). |
| `consumerFactory()` | Creates a `DefaultKafkaConsumerFactory<String, String>` bean used by the listener container. |
| `kafkaListenerContainerFactory()` | Creates a `ConcurrentKafkaListenerContainerFactory` with manual offset confirmation (`MANUAL_IMMEDIATE`) — equivalent to the original `consumer.commitSync()`. |

---

### model / `IncidentRecord.java`
A domain object representing a single incident record extracted from a Kafka message. Contains 10 fields identical to the original.

| Method | Description |
|--------|------|
| `toHashRow()` | Joins all 10 fields with the `$` separator and returns a ready-made row for writing to the output file. Equivalent to the original `String.join("$", ...)`. |
| `nullSafe(String value)` | Private helper method — returns an empty string instead of `null`, prevents NPE in `toHashRow()`. |

Fields: `number`, `serviceOffering`, `shortDescription`, `formattedTimestamp`, `state`, `formattedCreatedOn`, `formattedClosedAt`, `assignedTo`, `assignedToUserName`, `assignmentGroup`.

---

### model / `ConsumerRunStats.java`
Immutable snapshot of the statistics for a single consumer run. Returned by the REST endpoint and logged at the end of the run.

Fields: `runId`, `startTime`, `endTime`, `totalChecked`, `filteredCount`, `errorCount`, `filteredOutCount`, `durationMs`, `durationSeconds`, `durationMinutes`, `durationHours`, `outputFileSizeBytes`, `outputFileLineCount`, `running`.

No custom methods - generated by the Lombok `@Builder`.

---
